# Tourist attraction reservation service
관광지 예약 및 리뷰, 문의 사이트


## 주제

지역 기반 관광지 예약 및 리뷰 사이트는 사용자가 다양한 관광 명소를 예약하는 것을 돕는 시스템 입니다. 일반 회원 는 관광지 리스트를 보면서 원하는 관광지를 쉽게 검색하거나 예약할 수 있으며, 관광지 관리자도 예약자 명단을 보거나, 관광지 관리를 할 수 있습니다. 추가적으로 서비스 회원들은 게시글을 통해 리뷰나 문의를 남길 수 있으며, 댓글을 통해 서로 소통이 가능합니다.


## 개발 환경

 - **programming Language**: `JAVA 21`
 - `Spring Boot 3.4.3`
 - `JPA`, `Lombok`, `Spring Security`
 - **DataBase**: `MySQL`
 - **Front End**: `Thymeleaf`, `JavaScript`
 - **IDE** : `IntelliJ IDEA` , `MySQL Workbench`
 - `GitHub`, `Docker`, `Docker compose`

   
## 역할
이승찬 : 관광지 구분, 관광지 지역, 관광지, 관광지 예약 관련 기능
윤석효 : 게시글 관련 기능 설계 및 구현, 게시글 관련 UI 수정, 댓글 관련 기능 일부 수정

#### 회원 기능

#### 관광지 관리 및 예약 기능

- 관광지 구분 쓰기, 읽기, 수정, 삭제 
  - 전체 관리자 권한인 유저는 쓰기, 읽기, 수정, 삭제 기능을 사용할 수 있다. 
  
- 관광지 지역 쓰기, 읽기, 수정, 삭제 
  - 전체 관리자 권한인 유저는 쓰기, 읽기, 수정, 삭제 기능을 사용할 수 있다. 
  
- 관광지 쓰기, 읽기, 수정, 삭제 
  - 전체 관리자 권한인 유저는 관광지를 읽기, 수정, 삭제 기능을 사용할 수 있다. 
  - 관광지 관리자 권한인 유저는 유저별 1개의 관광지를 쓰기, 수정 기능을 사용할 수 있다. 
  - 사용자 권한인 유저는 관광지를 읽기 기능을 사용할 수 있다. 
  
- 관광지 예약 쓰기, 읽기, 수정, 삭제 
  - 전체 관리자 권한인 유저는 관광지 예약을 쓰기, 읽기, 수정, 삭제 기능을 사용할 수 있다. 
  - 관광지 관리자 권한인 유저는 관광지 예약을 쓰기, 읽기, 수정, 삭제 기능을 사용할 수 있다. 
  - 사용자 권한인 유저는 관광지 예약을 쓰기, 읽기, 수정 기능을 사용할 수 있다. 

-오류처리 
  - 사용자의 입력값은 js를 통해 검증을 수행한다. - /js/'*' + Validate.js 
  - 사용자의 입력값은 Service에서 기능을 수행하기 전에 검증을 수행한다. - '*'Dto.validate() 
  - Service에서 예외가 생겼을 경우 /ENUM/'*'Message.java에 작성된 에러 메세지를 Controller로 반환한다. 
  - 반환된 메세지는 html페이지와 함께 "message"라는 변수명으로 보내진다. 
  - 받아온 "message" 변수의 값이 있을 경우 /js/alert.js 함수를 통해 사용자에게 보여진다. 
  

#### 게시글 및 댓글 기능

- 게시글 쓰기, 읽기, 수정, 삭제
  - 게시글 종류에는 `일반`, `리뷰`, `문의`, `신고`, `공지` 가 있다.
  - 게시글은 종류별로 모아서 볼 수 있으며, 페이지 기능과 다양한 옵션이 포함된 검색 기능이 있다.
  - 게시글 종류에 따라 이미지를 포함하거나, 평점, 관광지를 선택할 수 있다.
  - 사용자의 권한에는 `일반 유저`, `관광지 관리자`,`관리자` 가 있으며, 사용자의 권한별로 게시글 읽기, 쓰기, 삭제, 수정을 제한하였다.


- 게시글 권한별 적용 사항
   - 일반 사용자
      - `일반`, `리뷰`, `문의`, `신고` 게시글을 작성할 수 있다.
      - `일반`, `리뷰`를 제한없이 읽을 수 있으며, `문의`, `신고` 는 본인이 작성한 것만 읽을 수 있다.
      - 게시글 수정,삭제는 본인이 작성한 것만 가능하다.
        
   - 관광지 관리자
      - `일반`, `문의`, `신고` 게시글을 작성할 수 있으며, `리뷰`는 본인 관광지 대상으로만 작성 할 수 있다.
      - `일반`, `리뷰` 게시글을 제한없이 읽을 수 있으며, `문의`는 본인 관광지 대상으로 한 게시글만 읽을 수 있다.
      - 게시글 수정,삭제는 본인이 작성한 것만 가능하다.
    
   - 전체 관리자
      - `일반`, `리뷰`, `문의`, `신고`, `공지`를 작성할 수 있다.
      - `일반`, `리뷰`, `문의`, `신고`, `공지`를 제한없이 읽을 수 있다.
      - 게시글 수정은 본인이 작성한 것만 가능하며, 게시글 삭제는 제한없이 가능하다.

- 댓글 쓰기, 읽기, 수정, 삭제
  - 모든 게시글에는 댓글 작성이 가능하다.
  - 사용자의 권한별로 댓글 읽기, 쓰기, 삭제, 수정을 제한하였다.
 
- 댓글 권한별 적용 사항
   - 일반 사용자
   - 관광지 관리자
   - 전체 관리자
  
- 오류 처리

## 도커 환경에서 구동 방법(윈도우 기준)

 1. Docker와 Docker compose를 설치한다.
 2. docker-compose-extra-2.yml 파일을 다운로드 받는다.
 3. mysql-init/init.sql 파일을 다운로드 받아서 ./mysql-init 에 위치 시킨다.
 4. cmd 창에서 docker-compose-extra-2.yml 파일이 있는 위치로 이동하고 'docker compose -f docker-compose-extra-2.yml up -d' 명령을 실행한다.
 5. 'localhost:8080'(기본값)으로 접속하면 서비스를 운영할 수 있다.
  - docker-compose-extra-2.yml 파일, init.sql 파일 변경으로 다양한 설정값을 적용할 수 있다.
  - 초기 데이터는 github의 src/main/resources/data/insert_data.sql 파일을 사용하거나, ./sql 폴더에 직접 insert_data.sql 파일을 편집해서 사용해도 된다.
